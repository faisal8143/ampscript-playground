# Changelog

## 0.1.0

First release.

- Errors and warnings in the Problems panel as you type, checked against every test subscriber
- Live preview to the side, with subscriber picker and desktop/mobile width
- Test data from `<name>.data.json`, `ampscript.data.json` or AMPscript Core folders (`subscriber.json`, `DataExtensions/*.csv`, `Content/`)
- **AMPscript: Create Test Data File** builds a starter file from the template
- Completion, hover help and parameter hints for 70+ functions
- Syntax highlighting for AMPscript in HTML, `.amp` and `.ampscript` files
- JSON schema for test data files
