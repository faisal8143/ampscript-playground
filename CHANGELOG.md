# Changelog

## 0.2.0

- **CLI:** `ampscript check`, `render` and `init`, with GitHub Actions annotations (`--format github`) and `--strict`
- **Test data files:** `<name>.data.json`, shared `ampscript.data.json`, several test subscribers, CSV folders, and AMPscript Core project layout
- **VS Code extension** (`vscode/`): errors as you type, live preview, subscriber picker, completion, hover help, syntax highlighting
- Function reference with signatures for all 70+ supported functions
- TypeScript type definitions; published to npm as `ampscript-playground`

## 0.1.0

- AMPscript interpreter and browser playground
